# Project Overview and Getting Started Documentation Agents

The documentation system includes specialized synthesis agents that create high-level entry point documentation for wikis. Two critical agents - the Project Overview Agent and the Getting Started Agent - automatically generate foundation pages when the wiki reaches sufficient maturity (10+ pages).

The Project Overview Agent creates an architectural overview at `architecture/overview.md`, providing a bird's-eye view of the system's design, key components, and architectural decisions. The Getting Started Agent generates a practical guide at `guides/getting-started.md` with actionable steps for new developers: environment setup, project structure, local development commands, and recommended reading order. Both agents synthesize content from existing wiki pages rather than analyzing individual commits, making them meta-documentation tools that improve wiki usability.

The orchestration system tracks whether these critical pages exist through boolean flags (`hasProjectOverview`, `hasGettingStarted`) and prioritizes their creation when missing. This ensures that even large repositories with 1000+ commits eventually receive coherent, high-level documentation rather than just granular commit-level pages. The agents run with moderate temperature (0.4) for focused, practical output and have higher token budgets (2500) to accommodate comprehensive guides.

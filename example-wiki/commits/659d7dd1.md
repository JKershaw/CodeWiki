# Writer Agent - Encyclopedia-Style Content Transformation

The Writer Agent is a synthesis-level component in the multi-agent documentation system that transforms raw analysis content into polished encyclopedia-style wiki articles. Unlike analysis agents that process commits directly, the Writer Agent operates on existing wiki pages to improve their presentation quality and readability.

The agent identifies pages containing "commit-style" language (phrases like "This commit adds..." or "This modifies...") and rewrites them using present-tense, third-person documentation that explains what exists and why, rather than describing what changed. This transformation is critical for maintaining wiki quality, as raw analysis agents often generate content that reads like commit summaries rather than reference documentation. The Writer Agent acts as a quality gate, ensuring documentation serves as timeless reference material rather than historical change logs.

The implementation includes sophisticated detection logic that identifies pages needing rewriting by analyzing content patterns, checks for commit-style indicators in opening paragraphs, and prioritizes rewrites based on confidence scores. The orchestrator automatically triggers Writer Agent work when it detects pages with low-quality content, excluding inherently commit-focused categories like "commits/" and "security/". The agent processes one page per run to manage LLM costs, boosting confidence scores by 0.2 after successful rewrites to indicate improved content quality.

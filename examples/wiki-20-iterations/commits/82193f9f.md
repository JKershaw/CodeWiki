# Multi-Agent Wiki Documentation System

CodeWiki is a comprehensive documentation generation system that uses nine specialized AI agents to automatically create and maintain wiki documentation from git repositories. The system processes commits through two distinct phases: analysis agents that extract different types of information from code changes, and meta agents that enhance and organize the resulting wiki content.

The architecture employs five analysis agents that independently examine each commit: code-change agent for technical implementation details, narrative agent for architectural decisions and planning documents, security agent for vulnerability detection, pattern agent for design patterns and conventions, and dependency agent for tracking package changes. After the initial documentation is generated, four meta agents refine the wiki: link agent adds cross-references between related pages, structure agent analyzes organization, quality agent reviews content clarity, and consistency agent identifies gaps and conflicts across pages.

This example demonstrates the full system processing 16 commits to generate 41 wiki pages organized into categories (architecture, decisions, security, patterns, etc.) with automated cross-linking, security overviews, and quality metrics. The system achieved 56.1% average confidence across all generated content at approximately $2.50 total cost, showcasing practical LLM-based documentation generation at scale.

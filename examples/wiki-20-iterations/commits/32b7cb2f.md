# Overview Agent and Category Synthesis System

The Overview Agent is a synthesis agent that automatically generates Wikipedia-style overview pages for wiki categories. Unlike analysis agents that process individual commits, synthesis agents create higher-order documentation by analyzing existing wiki content. The Overview Agent specifically monitors categories that have accumulated multiple pages (minimum 3) but lack a unifying overview page, then generates comprehensive introductions that explain the category's scope, relate pages to each other, and provide navigation guidance.

The system implements a smart orchestration strategy that triggers overview generation at appropriate times. When a repository has at least 5 wiki pages total, the orchestrator groups pages by their top-level category path (e.g., "architecture", "components") and identifies categories lacking overview pages. It checks for existing work items and recent agent runs to avoid duplicate effort, then creates a single overview work item at a time with SYNTHESIS priority. Certain categories like "commits" are excluded since individual commit pages are too granular to benefit from category overviews.

The agent operates through the standard wiki processing pipeline rather than commit-based processing. When executed, it analyzes all pages within a category, extracts their summaries, and uses an LLM to generate a cohesive overview that introduces the topic, explains relationships between pages, highlights key concepts, and provides reading guidance. The generated overview includes confidence scoring and follows the same structured format as other wiki pages, ensuring consistency across the documentation system.

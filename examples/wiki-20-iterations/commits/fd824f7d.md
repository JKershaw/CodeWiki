# Markdown Export System

The markdown export system provides a way to extract wiki documentation from the CodeWiki database and save it as static markdown files. This capability enables version control of generated documentation, easier review of wiki content changes, and integration with static site generators or other markdown-based tools.

The export script (`scripts/export-wiki.ts`) queries the wiki database and writes each page to the filesystem in a structured directory hierarchy. The generated markdown files include YAML frontmatter with metadata (title, confidence, timestamps, source commits) and preserve the content structure. This creates a bridge between CodeWiki's dynamic, database-backed documentation and traditional file-based documentation workflows, allowing teams to track documentation evolution through Git and review changes using familiar diff tools.

The extensive set of example markdown files demonstrates the system's output across different categories: architecture documentation, commit analysis, architectural decision records (ADRs), coding conventions, security audits, and planning documents. These files serve both as examples of the system's capabilities and as a reference implementation showing the expected markdown structure and metadata format.

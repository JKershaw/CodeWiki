# Wiki Generation System - Full Example Documentation

The CodeWiki system includes a comprehensive full-wiki example that demonstrates the complete multi-agent documentation generation pipeline. This example showcases all nine specialized agents working together to analyze a repository's commit history and generate structured wiki documentation. The example consists of 86 documentation files organized across 14 categories, including architecture overviews, commit analyses, design decisions, security audits, and code patterns.

The generation process involves two phases: analysis agents that process individual commits (code-change, narrative, security, pattern, dependency agents) and meta-agents that refine the wiki structure (link, structure, quality, consistency agents, plus an overview synthesis agent). Each agent contributes specialized knowledge, creating a multi-dimensional view of the codebase that helps developers understand not just what changed, but why decisions were made, how components interact, and what patterns emerge.

The example demonstrates the system's ability to transform raw git history into organized, cross-referenced documentation that serves as both historical record and living knowledge base. Files are organized by concern (architecture, decisions, guides, security) rather than chronologically, making information discoverable by topic. The documentation includes confidence scores, showing the system's ability to self-assess the reliability of its analysis based on code clarity and available context.

# Node.js Test Runner Migration

The project's testing infrastructure has been migrated from Vitest to Node.js's built-in test runner, simplifying the testing setup while maintaining comprehensive test coverage. This migration removes the dependency on Vitest and its associated bundling infrastructure, reducing the project's dependency footprint and leveraging Node.js's native testing capabilities available since Node 18.

The testing architecture employs a minimal mocking strategy with custom test utilities that provide isolated test environments. The test suite includes unit tests for individual components like agents and services, integration tests for multi-component workflows, and end-to-end tests using Playwright. Test utilities create real repositories and git services with only the LLM service being mocked, ensuring tests run against actual implementations while avoiding external API calls. The migration maintains the existing test structure with helpers for creating test contexts, mock repositories, and fake LLM responses.

The Node test runner is configured to run both unit and integration tests using the `--import tsx` flag for TypeScript support, eliminating the need for a separate build step during testing. This approach aligns with the project's philosophy of minimizing external dependencies while maintaining robust testing practices for the wiki generation and agent-based processing pipeline.

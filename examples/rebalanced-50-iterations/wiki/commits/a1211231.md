# Rebalanced Wiki Generation System

The rebalanced wiki generation system optimizes the orchestrator's agent scheduling strategy to produce higher-quality documentation earlier in the generation process. The system addresses previous issues where agents were scheduled in strict sequential order, leading to sparse early coverage and delayed synthesis of meaningful content.

The orchestrator now employs a multi-strategy approach that bundles multiple analysis agents per commit (code-change, narrative, security, technical-debt, pattern, and dependency agents) to ensure comprehensive coverage before moving to the next commit. Meta agents (link, structure, quality, consistency) are activated earlier - after processing 20+ commits or achieving 50% coverage - rather than waiting for complete analysis coverage. Synthesis agents (overview, project-overview, getting-started, writer) trigger at lower thresholds (8+ pages instead of requiring extensive coverage), enabling the generation of high-level documentation sooner. The system includes comprehensive tooling for testing the rebalancing logic with mock LLMs and generating production wikis with detailed progress tracking, checkpoints, and exportable markdown output.

## Key Findings

- **FEATURE** (high): Agent bundling strategy ensures comprehensive commit coverage with multiple analysis agents per commit rather than sequential processing
- **FEATURE** (high): Early meta-agent activation triggers link/structure/quality agents after 20+ commits or 50% coverage instead of waiting for complete analysis [src/agents/orchestrator/orchestrator.ts]
- **FEATURE** (medium): Synthesis agents activate at 8+ pages threshold enabling overview and getting-started documentation generation sooner
- **FEATURE** (medium): Technical debt agent integrated into bundled analysis workflow for early code quality assessment
- **TOOLING** (medium): Rebalanced wiki generation script with progress tracking, checkpoints, and markdown export capabilities
- **TOOLING** (low): Testing framework with mock LLM to verify orchestrator rebalancing behavior and agent scheduling patterns

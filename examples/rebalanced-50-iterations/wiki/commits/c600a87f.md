# Example Wiki Directory Structure

The CodeWiki system maintains a clean separation between its core implementation and demonstration materials through its directory organization. The example-wiki directory previously served as a comprehensive demonstration of the system's capabilities, containing sample architecture documentation, commit analyses, coding conventions, and guides that illustrated how CodeWiki processes and structures repository knowledge.

This example content provided developers with concrete templates and patterns for understanding CodeWiki's output format, including how it transforms commit-style documentation into encyclopedia-style articles, organizes content by categories (architecture, commits, conventions, guides, patterns, planning), and maintains metadata like confidence scores and creation timestamps. The removal of this directory reflects a shift toward a cleaner repository structure focused on the core system implementation rather than maintaining extensive example outputs within the main codebase.

The CodeWiki system itself continues to operate through its established architecture with CQRS boundaries, repository patterns, and multi-agent processing pipelines. The core functionality for generating living documentation from Git repositories remains intact in the src/ directory, with the removal only affecting the demonstration materials that previously showed the system's output format and capabilities.

# Technical Debt Analysis Agent

The Technical Debt Analysis Agent is a specialized code quality analyzer that automatically identifies and tracks technical debt in software repositories. Operating as part of the multi-agent analysis pipeline, this agent examines code changes to detect maintainability issues, complexity problems, and code smells that accumulate over time. The agent uses an LLM-powered analysis system to evaluate commits against eight categories of technical debt indicators: complexity issues (long functions, deep nesting), code duplication, technical shortcuts (TODO/FIXME comments, magic numbers), maintainability concerns (tight coupling, large parameter lists), code smells (god classes, feature envy), missing abstractions, test coverage gaps, and documentation debt.

The agent operates on a sophisticated debt classification system with five severity levels (critical, high, medium, low, none) and generates structured findings that include the debt type, severity, description, and affected file paths. Beyond simple detection, it tracks debt evolution by identifying both newly introduced debt and debt that has been resolved through refactoring efforts. For significant debt findings, the agent automatically generates comprehensive technical debt reports and maintains an overview tracking page that provides visibility into code quality trends and hotspots across the codebase.

The analysis employs intelligent filtering to focus on actionable findings while avoiding false positives, using configurable thresholds (functions >50 LOC, nesting >4 levels, >5 parameters) and contextual understanding to distinguish between legitimate technical shortcuts and problematic debt accumulation.

# Wiki Export System

The wiki export system provides a mechanism to convert the CodeWiki database into static Markdown files organized in a hierarchical directory structure. This enables version control integration, offline access, and easy sharing of documentation without requiring access to the running CodeWiki system or database. The export script reads all wiki pages from MongoDB and generates corresponding Markdown files with frontmatter metadata, preserving the original page structure, relationships, and confidence scores.

The export functionality bridges the gap between CodeWiki's database-driven documentation system and traditional file-based documentation workflows. By generating static Markdown files, teams can commit documentation to Git repositories, review changes through pull requests, and distribute documentation through standard web hosting or documentation platforms. The exported files maintain full traceability through embedded commit references and metadata, ensuring the static export remains connected to its source analysis.

The implementation creates a comprehensive snapshot of the wiki state, organizing pages by their path hierarchy (architecture/, decisions/, security/, etc.) and generating an index page that provides navigation. Each exported page includes YAML frontmatter with title, confidence score, creation/update timestamps, and source commit references, making the exports suitable for static site generators and documentation tools.

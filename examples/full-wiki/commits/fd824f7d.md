# Commit fd824f7d

Add markdown export script for wiki pages

## Summary

This commit adds a markdown export script to generate static markdown documentation from the wiki database. The script exports all wiki pages from MongoDB into a hierarchical markdown directory structure under `examples/real-llm/markdown/`, preserving the wiki's organization (architecture/, commits/, decisions/, etc.) and adding YAML frontmatter with metadata. This enables version-controlled, git-friendly documentation that can be browsed without the database, and potentially published to GitHub Pages or other static site generators.

## Findings

- **FEATURE** (high): New export functionality converts living wiki database into static markdown files with frontmatter, enabling git-based workflows, static site generation, and offline browsing. Related paths: scripts/export-wiki.ts, examples/real-llm/markdown/
- **ARCHITECTURAL_DECISION** (high): Maintains dual representation of documentation: dynamic database for the application and static markdown for git/web publishing. This hybrid approach balances real-time updates with version control benefits. Related paths: scripts/export-wiki.ts, examples/real-llm/markdown/index.md
- **METADATA_PRESERVATION** (medium): Frontmatter includes confidence scores, timestamps, and commit links, preserving the provenance and quality signals from the original wiki entries. Related paths: examples/real-llm/markdown/architecture/, examples/real-llm/markdown/decisions/
- **ORGANIZATION_PATTERN** (medium): Export maintains semantic categorization with folders for architecture/, decisions/, commits/, planning/, security/, patterns/, and conventions/, demonstrating intentional information architecture. Related paths: examples/real-llm/markdown/

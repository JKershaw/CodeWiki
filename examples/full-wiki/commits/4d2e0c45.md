# Link Agent - Wiki Cross-Reference System

The Link Agent is a meta-agent that analyzes wiki pages to discover semantic relationships and create cross-references between related content. Unlike domain-specific agents (code analysis, security, patterns), meta-agents examine and improve the wiki structure itself. The Link Agent transforms isolated, commit-based documentation into an interconnected knowledge graph by identifying pages that discuss related topics, components, or concepts.

This agent addresses a fundamental challenge in automated documentation: individual commits may create encyclopedic pages about specific features, but without explicit connections between them, developers must manually search to find related information. The Link Agent runs after other agents have populated the wiki, examining page titles, content, and metadata to suggest bidirectional links. For example, it might link a security audit page to the architectural overview of the component being audited, or connect multiple pages discussing the same design pattern.

The implementation uses a two-phase approach: first, it batches pages for efficiency (analyzing up to 20 pages per LLM call), then updates each page with discovered relationships. The agent records both outbound links (on the source page) and ensures the `relatedPages` metadata is populated. Test results show successful operation with 21 pages, creating 10 pages with links across two agent runs, demonstrating the batching strategy working effectively. The agent is designed to be idempotent - pages with existing links are skipped unless confidence is low, preventing unnecessary API costs on subsequent runs.

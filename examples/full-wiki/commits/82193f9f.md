# Full Wiki Example: Multi-Agent Documentation System

The full wiki example demonstrates a complete multi-agent documentation generation system that processes git commits through 9 specialized AI agents to create comprehensive project documentation. This example represents a mature implementation of the CodeWiki architecture, showcasing how different types of agents (analysis agents and meta agents) work together to transform code changes into structured, cross-referenced wiki documentation.

The system processes commits through five analysis agents that examine different aspects of code changes: code-change agent for technical documentation, narrative agent for ADRs and planning docs, security agent for vulnerability analysis, pattern agent for coding conventions, and dependency agent for package management. After the initial analysis, four meta agents post-process the generated wiki: link agent adds cross-references, structure agent analyzes organization, quality agent reviews content, and consistency agent identifies issues like orphaned pages. This two-phase approach ensures that documentation is not only comprehensive but also well-organized and interconnected.

The example includes 16 commits that generated 41 wiki pages across multiple categories (architecture, decisions, security, guides, etc.), with an average confidence of 56.1% and a total processing cost of approximately $2.50. The resulting wiki demonstrates practical patterns like ADR extraction from commit messages, aggregated security overviews, automatic cross-referencing between related pages, and quality metrics that help identify documentation gaps. This serves as both a reference implementation and a validation of the multi-agent architecture's effectiveness.

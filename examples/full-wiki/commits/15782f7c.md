# Anthropic Claude LLM Integration

The CodeWiki system includes an integration with Anthropic's Claude AI models to provide intelligent analysis of code changes and generate wiki documentation. This integration uses the official Anthropic SDK (@anthropic-ai/sdk v0.52.0) to communicate with Claude's API, enabling the system to leverage large language models for understanding code context, analyzing diffs, and producing human-readable documentation.

The LLM service architecture follows a provider pattern with a base `LLMService` interface and a concrete `AnthropicLLMService` implementation. This design allows the system to potentially support multiple LLM providers in the future while maintaining a consistent interface for the rest of the application. The service is exported through a centralized index, making it easily accessible throughout the codebase. The CLI has been updated to orchestrate the workflow: it uses the git service to extract commit information and diffs, then passes this data to the Anthropic service for analysis and documentation generation.

This integration represents a shift from mock or rule-based documentation generation to genuine AI-powered code understanding. The system can now provide intelligent insights about code changes, explain architectural decisions, identify patterns, and generate comprehensive wiki articles that capture both technical implementation details and higher-level design rationale. The use of Claude specifically suggests a focus on nuanced understanding and detailed technical writing capabilities.

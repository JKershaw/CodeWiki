# Commit c69224ba

Add core processing pipeline with CLI

## Summary

This commit establishes the core processing pipeline for CodeWiki, implementing a complete agent-based architecture for analyzing git commits and generating wiki documentation. It introduces a CLI interface, an orchestrator pattern for managing agent execution, a code-change agent for analyzing commits, service abstractions for LLM and Git operations, and an executor for applying wiki updates. The system follows a clean separation of concerns with agents, services, and execution layers, setting up the foundation for extensible commit analysis.

## Findings

- **ARCHITECTURE** (high): Implements agent-based architecture with orchestrator pattern for extensible commit analysis pipeline
- **DESIGN_PATTERN** (high): Uses dependency injection through AgentContext to provide services (LLM, Git, repos) to agents
- **AI_INTEGRATION** (high): Code-change agent uses structured prompts with token budgets (200k) and confidence scoring (0-1) for LLM-based analysis
- **EXTENSIBILITY** (medium): Agent interface allows multiple analysis types through AgentType union, enabling specialized agents beyond code-change
- **DATA_MODEL** (medium): Wiki updates support three merge strategies (create/update/merge) with confidence deltas for tracking reliability
- **COST_TRACKING** (medium): LLM service interface includes cost tracking (costUsd) for monitoring API expenses
- **CLI_TOOLING** (medium): Package.json adds CLI entry point and build configuration for command-line usage
- **PARSING_LOGIC** (medium): Custom regex-based parsing extracts structured data from LLM responses (SUMMARY/FINDINGS/WIKI_UPDATES format)
- **PATH_CONVENTIONS** (low): Enforces lowercase-with-hyphens naming for wiki paths (e.g., "architecture/cqrs-pattern")
- **MOCK_IMPLEMENTATION** (low): Mock LLM service provided for testing without API costs

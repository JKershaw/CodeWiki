# Commit 84389967

Add Research Agent and MCP server for wiki querying

## Summary

This commit introduces a Research Agent and MCP (Model Context Protocol) server to enable programmatic querying of the wiki. The change adds the `@modelcontextprotocol/sdk` dependency and implements two major components: a research agent for intelligent wiki queries and an MCP server that exposes wiki functionality through a standardized protocol. This architectural enhancement allows external tools and AI assistants to interact with the wiki programmatically, enabling automated documentation retrieval and context-aware assistance.

## Findings

- **ARCHITECTURE** (high): Introduces Model Context Protocol (MCP) integration, enabling standardized communication between AI tools and the wiki system. This follows the emerging pattern of tool-use APIs for LLMs.
- **FEATURE** (high): New Research Agent added to the agent system, likely handling natural language queries against wiki content and providing intelligent responses. Extends the existing agent architecture.
- **DEPENDENCY** (medium): Added @modelcontextprotocol/sdk v1.22.0 with extensive dependencies (Express 5.x, Zod, CORS, rate limiting). The SDK brings its own Express instance which may need coordination with existing Express usage.
- **INTEGRATION** (medium): CLI updated to support new research/MCP functionality, suggesting new command-line interface options for querying and server management.
- **TECHNICAL_DEBT** (low): Express version conflict potential - MCP SDK uses Express 5.x while the project may have been using 4.x. Need to verify compatibility and consider standardizing.
- **PATTERN** (medium): Agent system demonstrates extensibility - adding research agent alongside existing agents shows a plugin-like architecture for different documentation analysis capabilities.

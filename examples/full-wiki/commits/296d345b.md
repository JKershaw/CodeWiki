# Commit 296d345b

Enable multi-agent processing in executor and orchestrator

## Summary

This commit implements multi-agent processing throughout the CodeWiki system. Previously, only the code-change agent was active. Now all five analysis agents (code-change, narrative, security, pattern, dependency) are registered in the executor and the orchestrator generates work for all of them. The orchestrator implements a sequential processing strategy where code-change establishes base wiki content first, then specialized agents add their perspectives. Each commit tracks which agents have processed it via a `processedBy` array, enabling incremental multi-agent processing without reprocessing. The work summary now includes per-agent coverage metrics.

# Markdown Export System for Wiki Documentation

The markdown export system provides a bridge between CodeWiki's database-backed documentation and traditional markdown-based documentation workflows. This capability allows teams to export their living documentation to static markdown files, enabling integration with existing documentation tools, static site generators, and version control workflows.

The system organizes exported content into a structured directory hierarchy that mirrors the wiki's logical organization: architecture, decisions, planning, security, patterns, commits, and conventions. Each markdown file includes YAML frontmatter with metadata (title, confidence scores, creation/update timestamps, and source commit references), ensuring traceability between the exported documentation and its source commits. This design supports both one-time exports and continuous synchronization scenarios.

The export functionality represents a pragmatic recognition that while CodeWiki generates and maintains documentation dynamically, teams often need documentation in portable, human-readable formats for code review workflows, external documentation hosting, or archival purposes. The structured output format ensures that exported documentation remains machine-parseable while being fully readable by humans.

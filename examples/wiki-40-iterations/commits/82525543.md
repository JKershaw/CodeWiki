# Structure Agent and Enhanced Page Naming System

The wiki generation system employs a Structure Agent as part of its multi-agent architecture to analyze repository organization and identify high-level documentation opportunities. This meta-agent examines the entire wiki structure to detect gaps, suggest reorganization, and propose new pages that would improve documentation coverage. Unlike narrative agents that focus on individual commits, the Structure Agent takes a holistic view of the documentation landscape.

The system has been enhanced with improved page naming capabilities. When agents analyze commits or repository structure, they now generate short, descriptive titles (3-6 words) that capture the essence of the content, such as "Web Interface Design" or "Multi-Agent Architecture". This replaces the previous approach of using generic or commit-based names, making the wiki more navigable and professional. The page titles are separate from the technical path identifiers, allowing for human-friendly names while maintaining organized file structures.

A comprehensive testing and review workflow has been introduced through the `generate-and-review.ts` script. This orchestration tool runs the complete wiki generation pipeline, tracks agent execution statistics, calculates costs, and exports the resulting wiki to markdown format for quality review. The script processes recent commits, manages iteration budgets, and provides detailed breakdowns of agent activity by type, making it easier to validate system behavior and documentation quality.

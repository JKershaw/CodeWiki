# Synthesis Agents: Project Overview and Getting Started Documentation

The synthesis agent system includes specialized agents that create high-level documentation by exploring the actual codebase and synthesizing existing wiki content. Two critical agents—`project-overview` and `getting-started`—generate essential entry-point documentation when a wiki reaches sufficient maturity (10+ pages).

The **Project Overview Agent** creates a comprehensive project-level overview at `architecture/overview.md` by reading source files like README.md and PLAN.md directly from the repository. It uses the LLM's tool-calling capabilities to explore the codebase, understanding the project's purpose, architecture, and key components from actual documentation rather than just wiki pages. This agent provides the "what is this project" page that serves as the primary introduction for new developers.

The **Getting Started Agent** produces practical onboarding documentation at `guides/getting-started.md` by reading package.json, exploring directory structures, and examining entry points. It generates actionable steps—actual commands to run, real file paths to explore, and verified setup instructions—rather than generic getting-started content. Both agents leverage codebase exploration tools (read_file, list_directory, search_files) to ensure documentation reflects the actual state of the code.

The orchestrator tracks whether these key pages exist through `hasProjectOverview` and `hasGettingStarted` flags in its context gathering, prioritizing their creation when wikis reach 10-15+ pages. This threshold-based approach ensures that even repositories with thousands of commits receive essential synthesis documentation early, rather than drowning in granular commit-level pages. The agents complement the existing `overview` agent, which creates category-level overviews, by providing project-wide synthesis that helps developers understand the entire system at a glance.

# Agentic Tool Use in Project Overview Agent

The Project Overview Agent employs an agentic tool-use pattern that allows the language model to autonomously explore the codebase by reading source files, searching for patterns, and inspecting directory structures. Unlike traditional approaches where all context must be pre-loaded into the prompt, this implementation provides the LLM with a set of tools (`read_file`, `search_files`, `list_directory`) that it can invoke iteratively during generation. The agent instructs the model to read key documentation files like README.md and PLAN.md directly from the repository, enabling it to gather authoritative information about the project before synthesizing an overview page.

This architectural pattern leverages Claude's tool-calling capabilities through a multi-turn conversation loop. When the LLM needs information, it requests tool executions (e.g., "read_file: README.md"), the system executes these requests and returns results, and the LLM continues reasoning with the new information. The system implements safeguards including a maximum of 5 tool rounds, path validation to prevent directory traversal attacks, and file size limits (50KB for overview generation, 100KB default) to prevent resource exhaustion. The agent tracks all tool invocations as findings in its run results, providing observability into which files were consulted during overview generation.

The implementation introduces a `completeWithTools` method on the LLMService interface that handles the agentic loop. The Anthropic implementation manages the conversation history, appending tool use blocks and tool result blocks in the proper message sequence, while automatically handling cases where the model exhausts its tool budget by prompting it to produce final output. This approach significantly improves documentation quality by grounding the overview in actual project artifacts rather than inferring structure from commit-based wiki pages, which may be incomplete or outdated. The pattern is designed for reuse across other synthesis agents where direct source access improves accuracy.

# Coding Standards & Conventions

## Observed Conventions

- **Documentation Philosophy**: Encyclopedia-style present-tense documentation enforced throughout system, rejecting commit-history narrative style
- **Confidence Scoring**: Systematic confidence tracking (0.50 shown in examples) for quality assessment and improvement prioritization
- **Metadata Structure**: Consistent frontmatter with title, confidence, created/updated timestamps, and commit references
- **File Organization**: Clear hierarchical structure with dedicated directories for architecture, commits, conventions, guides, patterns, and planning
- **Agent Naming**: Specialized agent roles with clear responsibilities (Writer Agent, Overview Agent, Analysis Agents, Meta Agents)
- **Audit Trail**: Comprehensive logging of orchestration decisions, execution results, and performance metrics

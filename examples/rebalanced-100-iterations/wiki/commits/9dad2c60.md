# CodeWiki Ignore System

The CodeWiki ignore system provides selective file filtering for repository analysis, similar to how .gitignore works for Git. The system uses a .cwignore file in the repository root to specify patterns for files and directories that should be excluded from code analysis. This filtering is applied throughout the codebase exploration tools, ensuring that generated content, build artifacts, and other irrelevant files don't interfere with the analysis process.

The ignore system follows .gitignore syntax conventions, supporting glob patterns, directory patterns (with trailing /), and comment lines. It automatically merges user-defined patterns with sensible defaults like node_modules/** and .git/**, ensuring essential directories are always excluded. The system includes performance optimizations through pattern caching and integrates seamlessly with the fast-glob library for efficient file matching. All codebase exploration tools (read_file, search_files, list_directory) respect these ignore patterns, providing a consistent filtering experience across the entire analysis pipeline.

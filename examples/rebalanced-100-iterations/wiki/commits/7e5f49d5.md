# Progressive Wiki Generation Examples

The progressive wiki generation examples demonstrate the evolution of a multi-agent documentation system across different iteration counts (1, 2, 5, 10, 20, and 50 iterations). These examples provide snapshots of how the system's data structures and processing evolve as more commits are analyzed and more wiki content is generated. Each example directory contains six key data files that represent the complete state of the system at that point in the progression: agent runs, commits, orchestrator runs, repositories, wiki pages, and work queue items.

The examples serve as both test fixtures and documentation artifacts, showing how the system scales from analyzing a single commit to processing dozens of commits with multiple analysis agents. The progression reveals how wiki content becomes more comprehensive and interconnected as the system processes more code changes, with agents building upon previous analysis to create richer documentation. The data shows the multi-agent architecture in action, where different specialized agents (code-change, narrative, security, technical-debt, pattern, dependency) collaborate to analyze commits from various perspectives and generate cohesive wiki documentation.

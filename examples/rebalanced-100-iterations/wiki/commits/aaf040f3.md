# Node.js Test Runner Migration

The testing infrastructure has been migrated from Vitest to Node.js's built-in test runner, eliminating external testing framework dependencies while maintaining comprehensive test coverage. This architectural decision reduces bundle size by removing Vitest and its associated dependencies (including Rollup platform-specific binaries and Jest schemas), streamlining the development environment.

The migration preserves the existing test structure with unit tests for individual components (agents, tools, services) and integration tests for complete workflows. A minimal mocking infrastructure has been implemented using plain TypeScript classes, with the MockLLMService providing predictable responses for testing AI-powered components without external API calls. The test execution is now handled through Node's native `--test` flag combined with TypeScript compilation via tsx, maintaining the same developer experience while reducing complexity.

The testing approach emphasizes real service integration where possible, using actual file repositories and git services in tests, with only the LLM service being mocked to ensure deterministic and fast test execution. This hybrid approach provides confidence in system integration while maintaining test isolation and speed.

# Agentic Tool Integration for Code Analysis

The Code Change Agent leverages agentic tool use to perform deeper code analysis by interacting with the codebase beyond just examining git diffs. The agent now integrates with a suite of codebase exploration tools that allow it to read complete source files, search for related files using glob patterns, and explore project structure through directory listings. This enhancement transforms the agent from a diff-only analyzer into a contextually-aware code investigator.

The integration uses a tool execution framework where the LLM can make function calls to access repository contents. The agent provides three primary tools: `read_file` for accessing complete file contents, `search_files` for finding related files through pattern matching, and `list_directory` for understanding project structure. The tool system includes safety measures like path validation to prevent directory traversal attacks and file size limits to prevent excessive memory usage. Tool usage is tracked and reported as findings, providing transparency into how the agent gathered its contextual understanding. This approach enables the agent to write more comprehensive and accurate wiki documentation by understanding the full context of code changes rather than relying solely on diff fragments.

# Technical Debt Analysis Agent

The Technical Debt Analysis Agent is a specialized component of the CodeWiki system that automatically identifies and tracks code quality issues in Git commits. This agent performs comprehensive technical debt analysis by examining code changes through multiple lenses including complexity, maintainability, duplication, and technical shortcuts. The agent leverages large language models to analyze commit diffs and provides structured findings with severity levels, actionable recommendations, and tracking of debt accumulation or reduction over time.

The agent integrates seamlessly with the multi-agent analysis pipeline, implementing the standard Agent interface with a dedicated `technical-debt` type. It processes commits by building detailed prompts that include commit metadata and diff content, then parses structured LLM responses to extract findings, debt levels, and recommendations. The agent maintains a sophisticated understanding of technical debt patterns including deep nesting (>4 levels), long functions (>50 LOC), magic numbers, TODO/FIXME comments, god classes, and missing abstractions. It tracks both debt introduction and debt reduction, making it valuable for monitoring refactoring efforts and code quality trends.

The agent automatically generates wiki documentation for significant technical debt findings, creating dedicated report pages for high or critical debt levels and maintaining an overview page that tracks hotspots and recommendations across the codebase. This provides development teams with persistent, searchable documentation of code quality evolution and actionable insights for technical debt management.

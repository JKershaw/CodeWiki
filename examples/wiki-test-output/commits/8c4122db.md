# Wiki Documentation Example System

The wiki documentation example system provides progressive demonstrations of how the CodeWiki system evolves documentation quality through iterative processing. The system includes four example scenarios (1, 5, 10, and 20 iterations) that showcase how multiple passes of analysis and meta-agent processing gradually improve wiki documentation from raw commit summaries to polished encyclopedia-style articles.

Each example directory contains the complete wiki output at that iteration count, including individual commit pages, synthesized overview pages, and category indexes. The examples demonstrate concrete progression: the 1-iteration wiki shows basic commit analysis with 50% confidence, the 5-iteration version adds initial structure improvements, the 10-iteration version includes overview pages and better cross-linking, and the 20-iteration version exhibits mature documentation with coding standards, architecture decision records, and anti-pattern documentation. The system also includes a comparison tool that allows developers to analyze how documentation quality metrics evolve across iterations, making the improvement trajectory measurable and transparent.

The CLI has been simplified to always use LLM-powered orchestration, removing the deterministic mode option. This architectural decision reflects a commitment to intelligent, context-aware work prioritization rather than rule-based scheduling. The orchestrator now exclusively uses AI models to analyze wiki state and determine optimal next steps, ensuring the system adapts to complex documentation needs rather than following rigid patterns.

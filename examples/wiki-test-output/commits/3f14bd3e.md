# Wiki Documentation Generation System Example

The full-wiki example demonstrates a comprehensive documentation generation system that uses multiple specialized AI agents to analyze git commits and produce structured wiki content. This example serves as both a showcase of the CodeWiki system's capabilities and a living documentation set that explains its own architecture and implementation.

The documentation system employs nine distinct agent types working in two phases: analysis agents that process individual commits to extract different perspectives (code changes, security implications, design patterns, architectural decisions, and dependency impacts), and meta agents that operate on the generated wiki to add cross-references, ensure consistency, maintain quality standards, and provide structural organization. This multi-agent approach allows the same source material to be examined through multiple specialized lenses, producing richer and more comprehensive documentation than a single-pass analysis could achieve.

The example includes 86 wiki pages across 14 categories, covering architecture documentation, security audits, design patterns, architectural decision records, and per-commit documentation. It demonstrates the complete workflow from commit analysis through meta-processing, including features like confidence tracking, cross-page linking, quality assessment, and automated index generation. The review document (REVIEW.md) provides a self-assessment of the generation quality, identifying both successful patterns (encyclopedic writing style, proper overview pages, effective cross-linking) and areas needing improvement (sparse content on some pages, inconsistent formatting in pattern documentation).

# Complete Multi-Agent Wiki Generation System

The CodeWiki system demonstrates a comprehensive approach to automated documentation generation from git repositories using a nine-agent architecture. The system combines five analysis agents that process individual commits (code-change, narrative, security, pattern, dependency) with four meta-agents that enhance and organize the resulting wiki (link, structure, quality, consistency). This dual-phase approach enables both depth of analysis on individual changes and holistic organization of the resulting knowledge base.

The example wiki processes 16 commits through all nine agents, generating 41 interconnected documentation pages across eight logical categories (architecture, commits, conventions, decisions, guides, history, patterns, planning, security). Each commit receives parallel analysis from the five specialized agents, producing different perspectives on the same changes - from technical implementation details to security implications to architectural decisions. The meta-agents then enhance this raw output by adding cross-references, identifying organizational improvements, assessing content quality, and ensuring consistency across related pages.

This architecture demonstrates several key principles: separation of concerns through specialized agents, incremental knowledge building through commit-by-commit processing, and iterative refinement through meta-agent passes. The system maintains confidence scores for each generated page (averaging 56.1% in this example), provides detailed cost tracking (~$2.50 for the full analysis), and generates comprehensive metadata linking pages to their source commits. The resulting wiki serves as both documentation and a knowledge graph, with explicit relationships between concepts, decisions, and implementations.

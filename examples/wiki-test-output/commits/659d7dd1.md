# Writer Agent - Encyclopedia-Style Content Transformation

The Writer Agent is a synthesis-layer component that transforms raw analysis pages into polished encyclopedia-style articles. It identifies wiki pages containing "commit-style" language (phrases like "this commit adds" or "this change introduces") and rewrites them as proper documentation that explains what systems do and why they exist, rather than describing what changed.

The agent operates as part of the orchestration system's work queue, automatically detecting pages that need editorial improvement. It uses pattern matching to identify raw analysis content, then employs an LLM to rewrite the content in third-person present tense, preserving factual information while adding context and clarity. The system prioritizes pages by confidence level, focusing first on lower-confidence content that needs the most improvement. Pages in certain categories like `commits/` and `security/` are deliberately excluded, as their commit-focused nature is appropriate for their purpose.

This represents a critical distinction in the wiki architecture: while most agents generate raw analysis directly from code changes, the Writer Agent is purely a synthesis component that never runs on commits. It consumes and improves existing wiki content, gradually transforming the documentation from technical analysis into accessible reference material. The agent boosts confidence scores after successful rewrites, signaling that content has been editorially refined.

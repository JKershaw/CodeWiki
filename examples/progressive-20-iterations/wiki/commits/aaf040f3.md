# Node.js Native Test Runner Migration

The test suite uses Node.js's built-in test runner (available since Node 20.4.0) instead of external testing frameworks like Vitest. This approach eliminates external dependencies for testing while providing modern testing capabilities including describe/it blocks, lifecycle hooks (before/after/beforeEach), and assertion utilities through the native `node:test` and `node:assert` modules.

The testing strategy employs a "minimal mocking" philosophy where only the LLM service is mocked, while all other components use real implementations. Test helpers provide isolated environments with real file-based repositories, real Git operations via simple-git, and a predictable MockLLMService that returns configurable responses. This integration testing approach validates actual system behavior rather than mocked interactions, catching real-world issues like file system operations, Git command execution, and repository state management.

The test infrastructure creates temporary directories for each test context, setting up complete working environments with Git repositories, wiki data storage, and all production services except the LLM. Tests can create commits, analyze them with agents, and verify that wiki pages are correctly generated and stored. The MockLLMService records all completion calls for assertions while allowing tests to configure specific responses for different prompts, enabling deterministic testing of agent logic without actual API calls.

## Key Findings

- **ARCHITECTURE** (high): Migration from Vitest to Node.js native test runner eliminates external test dependencies
- **TESTING** (high): Minimal mocking strategy uses real repositories, Git operations, and file system with only LLM mocked
- **INFRASTRUCTURE** (medium): Test context helpers create isolated temporary environments for integration tests
- **PATTERN** (medium): MockLLMService provides deterministic LLM responses without API calls while tracking usage
- **DEPENDENCY** (low): Removed Vitest and related packages (@jest/schemas, @jridgewell/sourcemap-codec, @rollup/*)
- **CONFIGURATION** (medium): Test script uses Node's --test flag with tsx import for TypeScript support

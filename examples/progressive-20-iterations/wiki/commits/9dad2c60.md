# Repository Ignore Patterns (.cwignore)

The CodeWiki system implements a `.cwignore` file mechanism to exclude specific files and directories from repository analysis. This feature follows the familiar `.gitignore` syntax, allowing users to define glob patterns that prevent certain paths from being indexed, read, or analyzed by the LLM-powered documentation system.

The ignore system operates at two levels: default patterns that are always excluded (like `node_modules/**` and `.git/**`), and custom patterns defined in a repository's `.cwignore` file. When CodeWiki's codebase exploration tools (read_file, search_files, list_directory) interact with a repository, they automatically load and apply these patterns using the `fast-glob` and `minimatch` libraries. This ensures generated content is derived from actual source code rather than build artifacts, generated documentation, or dependency directories.

The implementation includes intelligent pattern parsing that handles comments (lines starting with `#`), automatically converts directory patterns (ending with `/`) to glob patterns with `/**`, and caches parsed patterns per-repository to minimize file system reads. The system intentionally does not support negation patterns (`!pattern`) as the underlying `fast-glob` library's ignore option doesn't handle them. This design decision prioritizes simplicity and reliability over edge cases, with comprehensive test coverage validating pattern parsing, caching behavior, and integration with file exploration tools.

- **IMPLEMENTATION** (high): Pattern caching system stores loaded ignore patterns per repository path to avoid repeated file reads, with clearIgnoreCache() for testing and cache invalidation, src/services/cwignore.ts

- **DESIGN** (medium): Directory patterns ending with / are automatically converted to /**/ glob patterns for consistent matching behavior, src/services/cwignore.ts
- **CONSTRAINT** (medium): Negation patterns (starting with !) are intentionally not supported due to fast-glob limitations, explicitly skipped during parsing, src/services/cwignore.ts
- **DEPENDENCY** (medium): Added fast-glob (^3.3.2) and minimatch (^10.0.1) packages for robust pattern matching across different file operations, package.json
- **TESTING** (high): Comprehensive unit tests cover pattern parsing, caching, cache invalidation, and integration with file system operations, tests/unit/cwignore.test.ts

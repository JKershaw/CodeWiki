# Example Wiki Gallery - Agentic Tool-Using Agents

CodeWiki includes example wikis demonstrating different agent capabilities and output quality. The "wiki-20-iterations-agentic" example showcases a complete documentation set generated by agents equipped with agentic tool-use capabilities—a significant architectural enhancement that allows AI agents to autonomously explore codebases during their reasoning process.

This example wiki contains 19 pages across 8 categories (agents, architecture, components, conventions, guides, patterns, planning, and commits), with an average confidence score of 55%. Unlike traditional prompt-response agents that operate "blind" with only commit diffs, these agentic agents can iteratively call tools like `read_file`, `search_files`, and `list_directory` to build comprehensive context before generating documentation. The wiki demonstrates how agents that can explore actual source files produce dramatically higher quality output—grounded in real project artifacts like README.md and package.json rather than inferring structure from incomplete information.

The example serves multiple purposes: it provides a visual reference for evaluating output quality, demonstrates the documentation structure CodeWiki produces (with proper cross-linking, metadata, and confidence tracking), and showcases the capabilities of tool-using agents. The wiki includes detailed architectural documentation explaining the agentic tool-use pattern itself, implementation plans showing how the feature was designed, and commit-level analysis demonstrating how agents applied these capabilities across different types of documentation tasks. This self-documenting approach—where CodeWiki generates wikis explaining its own architecture—validates both the system's capabilities and the effectiveness of AI agents with codebase exploration tools.

# Writer Agent - Content Transformation System

The Writer Agent is a synthesis agent responsible for transforming raw analysis content into polished, encyclopedia-style wiki articles. Unlike other agents that analyze commits and generate initial documentation, the Writer Agent operates exclusively on existing wiki pages, identifying content that reads like commit summaries ("This commit adds...") and rewriting it in a professional, timeless article format.

This agent fills a critical gap in the documentation pipeline: while analysis agents excel at extracting information from code changes, they naturally produce commit-centric language. The Writer Agent bridges this gap by post-processing these raw analyses into proper reference documentation that explains "what exists" rather than "what changed." It uses heuristics to detect pages with commit-style indicators, examines related pages for context, and employs the LLM to rewrite content with a focus on present-tense, third-person explanations suitable for long-term documentation.

The agent integrates into the orchestrator's work queue system with synthesis-level priority, triggering automatically when pages are detected with commit-style content. It excludes certain categories (commits/, security/) and page types (overview pages) that are inherently commit-focused, and intelligently prioritizes pages with lower confidence scores that need the most refinement. Each rewritten page receives a confidence boost (+0.2 delta) to reflect the improved quality.

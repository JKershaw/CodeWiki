# Overview Agent for Category Synthesis

The Overview Agent is a synthesis agent that automatically generates Wikipedia-style overview pages for wiki categories once they reach sufficient size. Unlike analysis agents that process individual commits, synthesis agents operate on collections of existing wiki pages to create higher-order documentation. The Overview Agent specifically monitors categories and creates introductory pages that explain what the category covers, how pages relate to each other, and provide navigation guidance.

The agent activates when a category contains at least 3 pages but lacks an overview page (identified by paths like `category/overview` or `category/index`). It uses an LLM to analyze all pages in the category—extracting their titles, first paragraphs, and confidence scores—and synthesizes them into a cohesive introduction. This ensures that as the wiki grows organically through commit analysis, major topic areas automatically receive human-readable introductions that help developers navigate the documentation. The agent is integrated into the orchestration system's work queue prioritization, running at a lower priority than commit analysis to ensure new code changes are documented first.

Categories like "commits" are explicitly excluded from overview generation since they represent granular changelog-style content rather than conceptual topics. The agent includes deduplication logic to prevent creating multiple overviews for the same category, checking both existing wiki pages and pending work items. This design reflects a multi-tier documentation strategy: analysis agents create detailed technical pages from commits, while synthesis agents add structural elements that improve discoverability and comprehension.

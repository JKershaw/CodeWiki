# Synthesis Agent System - Project Overview and Getting Started

The synthesis agent system includes specialized agents that create high-level documentation by analyzing existing wiki content. Two critical synthesis agents ensure wikis provide essential entry points for developers: the Project Overview Agent and the Getting Started Agent.

The Project Overview Agent creates a comprehensive project overview at `architecture/overview.md` when the wiki reaches 10+ pages. This agent synthesizes content from multiple wiki pages to explain what the project does, its architecture, and key design decisions. The overview serves as the primary landing page for developers seeking to understand the system's purpose and structure.

The Getting Started Agent generates practical onboarding documentation at `guides/getting-started.md`, also triggered when the wiki reaches 10+ pages. Unlike the high-level overview, this guide focuses on actionable steps: setting up the development environment, running the project locally, making first changes, and identifying which files to read first. Both agents use the orchestrator's context gathering system to detect whether these critical pages exist, prioritizing their creation when missing. The orchestrator adjusts its decision-making based on page count thresholds, shifting from pure analysis (fewer pages) to synthesis work (more pages) as the wiki matures.

# Technical Debt Analysis Agent

The Technical Debt Agent is a specialized analysis agent within the CodeWiki system that automatically identifies and tracks code quality issues across Git commits. It functions as part of a multi-agent architecture where different agents examine code through specialized lenses—while SecurityAgent looks for vulnerabilities and PatternAgent recognizes design patterns, TechnicalDebtAgent focuses specifically on maintainability concerns and code smells.

The agent performs automated code quality audits by analyzing commit diffs through an LLM (Language Model), evaluating changes across eight key dimensions: complexity issues (long functions, deep nesting), code duplication, technical shortcuts (TODO/FIXME comments, magic numbers), maintainability concerns (tight coupling, large parameter lists), code smells (god classes, feature envy), missing abstractions, test coverage gaps, and documentation debt. It categorizes technical debt severity into five levels (critical, high, medium, low, none) and tracks not just debt accumulation but also debt reduction through refactoring efforts.

The agent integrates into CodeWiki's orchestration pipeline alongside five other analysis agents (code-change, narrative, security, pattern, and dependency). Each commit is processed by all analysis agents to build comprehensive documentation from multiple perspectives. When TechnicalDebtAgent identifies significant issues (critical or high severity, or multiple findings), it automatically generates wiki pages under `technical-debt/` that document the specific problems, provide actionable recommendations, and track code quality hotspots—files that are accumulating debt over time. This creates a living record of technical debt that helps teams understand code health trends and prioritize refactoring work.

## Key Findings

- **Agent Architecture** (high): TechnicalDebtAgent implements the Agent interface and runs as part of a multi-agent analysis pipeline, processing commits through specialized lenses alongside SecurityAgent, PatternAgent, and others
- **LLM Integration** (high): Uses LLM completions with structured prompts to analyze diffs for eight categories of technical debt, with low temperature (0.2) for consistent code quality assessment
- **Wiki Generation** (medium): Automatically generates technical debt report pages for significant findings (high/critical severity or 2+ issues) and maintains a technical-debt/overview page tracking trends
- **Debt Tracking** (medium): Tracks both debt accumulation and debt removal, recognizing refactoring commits that reduce technical debt rather than just flagging problems
- **Response Parsing** (medium): Implements robust parsing of structured LLM responses including summary, debt level, issues list, debt added/removed, recommendations, hotspots, and confidence scores
- **Confidence Modeling** (medium): Agent confidence reflects certainty of technical debt assessment, with higher confidence delta (0.5) for critical issues vs. lower (0.1) for overview updates

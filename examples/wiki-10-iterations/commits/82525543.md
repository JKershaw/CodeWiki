# Structure Agent and Wiki Page Naming System

The Structure Agent is a meta-level agent that analyzes commit content holistically to identify high-level patterns, architectural decisions, and cross-cutting concerns that individual analysis agents might miss. Unlike agents that focus on specific commits, the Structure Agent examines clusters of related changes to understand broader themes and suggest appropriate wiki organization.

The agent introduces an intelligent page naming system that generates concise, descriptive titles for wiki content. Rather than using generic or commit-based names, the system creates meaningful titles (3-6 words) that capture the essence of the content, such as "Web Interface Design" or "Multi-Agent Architecture". This naming convention helps maintain a clean, navigable wiki structure where pages are organized by topic rather than chronological commit history.

The implementation includes a generate-and-review script that provides a complete pipeline for wiki generation with quality assessment. This script runs the full orchestration process, exports results to markdown format, and provides detailed statistics about page generation, agent activity, and categorization. The review workflow enables validation of wiki quality before publication, with confidence indicators and category breakdowns to identify areas needing improvement.

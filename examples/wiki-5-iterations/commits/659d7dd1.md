# Writer Agent: Encyclopedia-Style Content Generation

The Writer Agent is a synthesis agent responsible for transforming raw commit-style analysis into polished, encyclopedia-style wiki articles. Unlike analysis agents that document code changes, the Writer Agent operates on existing wiki content to improve its readability and professionalism. It identifies pages containing commit-oriented language (phrases like "this commit adds..." or "this change introduces...") and rewrites them in third-person, present tense to explain what systems do and why they exist, rather than how they were created.

The agent integrates into the orchestrator's work scheduling system with synthesis-level priority. It scans wiki pages to identify content needing improvement, specifically targeting pages outside inherently commit-focused categories (like `commits/` and `security/`) that contain commit-style indicators. The orchestrator triggers the Writer Agent when such pages are detected and no pending writer work exists. Once triggered, the Writer Agent processes one page at a time, using an LLM with carefully crafted prompts to rewrite content while preserving all factual information and technical details.

The Writer Agent's role is critical for maintaining wiki quality as the system scales. As analysis agents continuously generate new pages from commits, the Writer Agent ensures documentation evolves from raw technical notes into accessible, well-structured articles suitable for developer reference. It boosts page confidence scores after successful rewrites and can identify pages requiring expansion beyond simple language transformation, such as overly terse pattern documentation.

# Commit 60a1d836

Add web interface and E2E tests

## Summary

This commit adds a complete web interface for CodeWiki with a REST API server and comprehensive E2E test coverage using Playwright. The web UI provides views for managing repositories, browsing wiki pages, and querying documentation. The implementation includes a backend Express server serving both the API and static frontend assets, along with a full test suite covering API endpoints, repository operations, wiki functionality, and queries. The Playwright configuration is specifically optimized for containerized environments (like Claude Code on the web) with sandbox disabled and single-process mode.

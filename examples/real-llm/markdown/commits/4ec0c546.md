# Commit 4ec0c546

Add analysis agents: Narrative, Security, Pattern, Dependency

## Summary

This commit introduces a multi-agent analysis system for CodeWiki, implementing four specialized agents that analyze different aspects of code changes: DependencyAgent (tracks package dependencies), NarrativeAgent (generates human-readable documentation), PatternAgent (identifies architectural patterns), and SecurityAgent (detects security issues). The implementation follows a common Agent interface pattern with structured LLM prompts, response parsing, and wiki page generation capabilities. This represents a significant architectural decision to use specialized AI agents rather than a monolithic analyzer, enabling more focused and expert analysis of different code dimensions.

# Commit 296d345b

Enable multi-agent processing in executor and orchestrator

## Summary

This commit implements comprehensive multi-agent processing by activating all five analysis agents (code-change, narrative, security, pattern, dependency) in the executor and orchestrator. The orchestrator now generates work for all agents sequentially, with code-change establishing base wiki content first, followed by specialized agents adding their perspectives. The system tracks which agents have processed each commit via a `processedBy` array, enabling incremental multi-agent analysis. Date normalization was added to handle JSON serialization issues.

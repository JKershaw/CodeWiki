# Commit af17f139

Set up initial project structure with CQRS architecture

## Summary

This commit establishes the foundational architecture for CodeWiki using CQRS (Command Query Responsibility Segregation) pattern. The system is designed to generate living documentation from Git repositories by processing commits and maintaining a wiki. The architecture separates commands (state changes) from queries (state reads), implements a repository pattern with file-based storage, and defines core domain models for repos, commits, wiki pages, agent runs, conflicts, learnings, and work items. The structure supports future extensibility with multiple storage backends and agent types.

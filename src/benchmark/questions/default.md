# Default Benchmark Questions

These generic questions are used as a fallback when no repo-specific question file exists.
They cover common aspects of software projects that most codebases should document.

## project-structure

- **Category:** architecture
- **Difficulty:** easy
- **Hints:** src/

What is the overall structure of this project and how are the main directories organized?

## main-entry-point

- **Category:** architecture
- **Difficulty:** easy

What is the main entry point of the application and how does it initialize?

## core-abstractions

- **Category:** architecture
- **Difficulty:** medium

What are the core abstractions or domain models in this codebase?

## data-storage

- **Category:** decisions
- **Difficulty:** medium

How is data persistence handled in this project? What storage mechanisms are used?

## error-handling

- **Category:** patterns
- **Difficulty:** medium

How are errors handled throughout the codebase? Is there a consistent error handling pattern?

## configuration

- **Category:** conventions
- **Difficulty:** easy

How is application configuration managed? Where are config values defined and how are they accessed?

## testing-approach

- **Category:** conventions
- **Difficulty:** medium

What testing strategy is used? Where are tests located and how are they organized?

## dependencies

- **Category:** decisions
- **Difficulty:** easy

What are the main external dependencies and what purposes do they serve?

## api-design

- **Category:** architecture
- **Difficulty:** medium

If the project has an API, how is it structured and what conventions does it follow?

## security-practices

- **Category:** security
- **Difficulty:** medium

What security measures are implemented in this codebase?

## adding-features

- **Category:** howto
- **Difficulty:** hard

What is the recommended process for adding a new feature to this codebase?

## debugging

- **Category:** howto
- **Difficulty:** medium

How can developers debug issues in this application? What tools or techniques are available?
